2. Important FS methods
File operations
Method	Kaam
fs.readFile()	File ka data read karna
fs.readFileSync()	Synchronously file read karna
fs.writeFile()	File create karna ya existing file overwrite karna
fs.appendFile()	File ke end mein data add karna
fs.copyFile()	File copy karna
fs.rename()	File rename ya move karna
fs.unlink()	File delete karna
fs.open()	File open karna
fs.close()	File descriptor close karna
fs.stat()	File ki information lena
fs.access()	File access/permission check karna
fs.truncate()	File ka size reduce karna

fs.rmdir()	Empty folder delete karna
fs.rm()	File ya folder remove karna
fs.mkdtemp()	Unique temporary folder banana
